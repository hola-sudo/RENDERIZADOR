# Imágenes de la landing

Coloca aquí los archivos con estos nombres exactos. Mientras no existan,
la landing dibuja un marcador neutro en su lugar (no se rompe nada).

| Archivo               | Dónde sale                        | Proporción sugerida |
|-----------------------|-----------------------------------|---------------------|
| hero.jpg              | Imagen grande del hero            | 16:9 (2400×1350)    |
| tool-render.jpg       | Pestaña "Event Render"            | 4:5 o 1:1           |
| tool-video.jpg        | Pestaña "Transición de video"     | 4:5 o 1:1           |
| tool-upscale.jpg      | Pestaña "Upscale 4K"              | 4:5 o 1:1           |
| tool-history.jpg      | Pestaña "Historial"               | 4:5 o 1:1           |
| proceso.jpg           | Sección "Proceso"                 | 4:3                 |
| caso-1-antes.jpg      | Comparador, modelo 3D             | 16:9                |
| caso-1-despues.jpg    | Comparador, render generado       | 16:9                |
| caso-2-antes.jpg      | Comparador, caso 2                | 16:9                |
| caso-2-despues.jpg    | Comparador, caso 2                | 16:9                |
| caso-3-antes.jpg      | Comparador, caso 3                | 16:9                |
| caso-3-despues.jpg    | Comparador, caso 3                | 16:9                |

En el comparador, "antes" y "después" deben ser **el mismo encuadre**
(la misma vista de SketchUp y su render) para que el deslizador funcione.

Los nombres se configuran en `components/landing/content.ts`.
